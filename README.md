# ONG Plataforma — Front-end

Plataforma web para uma organização do terceiro setor, desenvolvida com **HTML5 semântico**, CSS3 e JavaScript vanilla como parte da disciplina **Desenvolvimento Front-end** (Experiência Prática I) do curso de Engenharia de Software — Universidade Cruzeiro do Sul.

> 🚧 Em desenvolvimento — README completo será publicado ao final do projeto.

## Estrutura de pastas

```
ong-plataforma-frontend/
├── index.html        # Página inicial (apresentação da ONG)
├── projetos.html     # Projetos sociais, voluntariado e doações
├── cadastro.html     # Formulário de voluntários/doadores
├── css/
│   └── style.css     # Estilos
├── js/
│   └── script.js     # Máscaras e validações do formulário
├── img/              # Imagens em PNG e WebP (logo também em SVG)
└── docs/             # Registro das respostas de cada etapa
```
