# EP2 · Etapa 2 — Componentes com Flexbox

| Nome do componente ou contentor | Propriedades Flexbox aplicadas |
|---|---|
| Cartões (.cartao) — Missão/Visão/Valores e Como ajudar (index) e Campanhas de doação (projetos) | display: flex; flex-direction: column; gap: var(--espaco-3); e margin-top: auto no último item (link, prazo ou local). O Grid dá a mesma altura aos cartões de uma linha, e o Flexbox empurra a última informação para a base, deixando links e prazos alinhados entre os cartões mesmo com textos de tamanhos diferentes. O gap substitui as margens, que não colapsam dentro do flex. |
| Cabeçalho (.cabecalho) no celular | display: flex; flex-direction: column; align-items: flex-start; gap: var(--espaco-3). Em telas estreitas, a logo e o menu ficam empilhados e alinhados à esquerda, sem disputar espaço na mesma linha. A partir de 768px o cabeçalho passa para o Grid de 12 colunas. |
| Marca / logo (.marca) | display: flex; align-items: center; gap: var(--espaco-2). Centraliza verticalmente o ícone e o nome da ONG no eixo cruzado, com espaçamento fixo entre eles vindo do Design System. |
| Menu de navegação (.menu) | display: flex; flex-wrap: wrap; gap: var(--espaco-1); list-style: none. Os itens da lista ficam em linha, e o flex-wrap faz os links quebrarem para a linha de baixo quando a tela é estreita, em vez de estourar a largura. Cada link tem display: block e padding, o que amplia a área de clique. |
| Grupo de botões (.acoes) — destaque da página inicial | display: flex; flex-wrap: wrap; gap: var(--espaco-3). Os botões "Quero ser voluntário" e "Conheça os projetos" ficam lado a lado e, quando não cabem, o segundo desce para a linha seguinte mantendo o mesmo espaçamento. |
| Campo do formulário (.campo) — cadastro.html | display: flex; flex-direction: column; gap: var(--espaco-2). Empilha rótulo, campo e texto de ajuda na ordem de leitura, com espaçamento uniforme. Cada .campo é ao mesmo tempo item do Grid do fieldset e contentor flex dos seus elementos. |
| Grupos de opções (.grupo-opcoes) — Tipo de apoio e Projetos de interesse | display: flex; flex-wrap: wrap; gap: var(--espaco-2) var(--espaco-4). Os botões de rádio e as caixas de seleção ficam lado a lado e quebram de linha em telas pequenas, com espaço vertical menor e horizontal maior para separar bem cada opção. |
| Consentimento LGPD (.consentimento) | display: flex; align-items: flex-start; gap: var(--espaco-2). Mantém a caixa de seleção ao lado do texto longo de autorização e alinhada à primeira linha dele, mesmo quando o texto quebra em várias linhas no celular. |
